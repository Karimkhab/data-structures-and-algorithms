# Data Structures and Algorithms (Innopolis University)

This repository contains coursework for the Data Structures and Algorithms course at Innopolis University. Each week has a problem set (PDF) and the corresponding solutions (`task_a`, `task_b`) when available. Task screenshots live inside each week folder.

## Course structure

- Lectures: general theory and intuition.
- Tutorials: deeper theory, proofs, and worked examples.
- Labs: coding + theoretical exercises with TA support and implementation demos.
- Books (self-study): extended explanations, proofs, and extra exercises.

## Assessment

- Quizzes during tutorials — 5% (short Moodle quizzes on the same day's lecture).
- Weekly exercises:
  - Coding exercises on Codeforces — 25%.
  - Theoretical exercises (PDF via Moodle) — 30%.
  - Only the best 3 out of 4 weeks count toward the final grade (per block grading policy).
- Midterm and Final exams — 20% + 20% (closed-book, in-class, theory).
